# Balise

Application Android libre et gratuite pour savoir où l'on est, partager sa position, retrouver un lieu enregistré.

Permet aussi d'envoyer un lien cliquable à un contact pour communiquer son emplacement ou qu'il communique le sien, pratique en situation d'urgence.

L'ensemble des numéros de secours et d'écoutes sont pré-enregistrés.

Widget permettant d'enregistrer très vite un emplacement.

Application utile pour les loisirs en groupe en plein air : chasse au trésors, battues, course d'orientation, centre aéré...

> ⚠️ Balise ne remplace pas les secours. En cas d'urgence, appelez le **112**
> (114 par SMS pour les personnes sourdes ou malentendantes).

## Fonctions

- [x] « Où suis-je ? » avec partage (SMS, WhatsApp, Messenger…)
- [x] Lieux enregistrés (voiture, magasin…) avec retour guidé
- [x] Demande de position par SMS, Whatsapp ou autre
- [x] Groupes pour activités de plein air

## Vie privée

Aucune donnée n'est envoyée à un serveur. La position n'est partagée que lorsque
vous appuyez sur le bouton de partage.

## Compiler

Android Studio, ou la compilation automatique GitHub Actions (voir `.github/workflows/build.yml`).
